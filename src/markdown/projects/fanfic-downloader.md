This was a plugin built out of frustration with the existing options for downloading fanfiction. The main other tool for this would ask for suspicious permissions, its source code was not available anywhere for me to doublecheck, and it didn't support many of the websites that are actually used by fanfiction communities.

So instead I built this, which can download from many different websites and into a variety of formats.
